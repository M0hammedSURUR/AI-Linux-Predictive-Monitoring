In-Scope

The project will include:

Monitoring of one Linux server
CPU monitoring
RAM and swap monitoring
Disk-space monitoring
Disk I/O monitoring
Network monitoring
System load monitoring
Process monitoring
Selected service monitoring
Selected system/application log monitoring
Historical telemetry storage
Data preprocessing
Feature engineering
Baseline behavior analysis
Anomaly detection
Selected predictive risk models
Prediction explanation
System health/risk scoring
Maintenance recommendations
Human approval workflow
Predefined safe remediation actions
Dry-run/simulation capability
Audit logging
Monitoring dashboard
Unit, integration and system testing
Performance and safety evaluation


Out-of-Scope

The initial implementation will not include:

Multi-server orchestration
Complete data-center management
Prediction of every possible Linux failure
Autonomous unrestricted shell-command execution
Automatic kernel modification
Automatic package upgrades
Destructive system cleanup
Enterprise-scale distributed monitoring
Guaranteed prediction of unknown failure types
