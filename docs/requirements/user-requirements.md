UR-01
The administrator should be able to monitor the current Linux server condition.

UR-02
The administrator should be able to view historical system behavior.

UR-03
The administrator should be informed when abnormal behavior is detected.

UR-04
The administrator should be able to view predicted system risks.

UR-05
The administrator should be able to understand the major factors contributing to a detected risk.

UR-06
The administrator should receive appropriate maintenance recommendations.

UR-07
The administrator should be able to approve or reject recommended corrective actions.

UR-08
The administrator should be able to review previous corrective actions.

UR-09
The administrator should be able to use a safe dry-run mode for testing corrective actions.

UR-10
The administrator should be able to configure appropriate monitoring parameters.
