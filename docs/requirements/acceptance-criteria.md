| Requirement           | Acceptance Criteria                                                   |
| --------------------- | --------------------------------------------------------------------- |
| Telemetry collection  | System successfully records configured Linux metrics with timestamps  |
| Historical monitoring | Dashboard displays previously collected telemetry                     |
| Anomaly detection     | Controlled abnormal behavior produces a detectable anomaly            |
| Prediction            | Selected test scenario produces a measurable risk prediction          |
| Explanation           | Prediction displays contributing features/factors                     |
| Recommendation        | Identified scenario produces an appropriate predefined recommendation |
| Approval              | Unapproved action cannot execute                                      |
| Rejection             | Rejected action is not executed                                       |
| Safe action           | Only registered/whitelisted actions can execute                       |
| Audit                 | Approval/rejection/execution is recorded                              |
| Dry run               | Dry-run produces no actual corrective change                          |
| Dashboard             | Current monitoring and risk information are visible through the UI    |
