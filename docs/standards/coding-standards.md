# Python Coding Standards

## Naming

- Classes use PascalCase.
- Functions and methods use snake_case.
- Variables use snake_case.
- Constants use UPPER_SNAKE_CASE.

## Documentation

- Public classes and methods should have docstrings.
- Complex logic should contain explanatory comments where necessary.

## Type Hints

Type hints should be used for public interfaces where practical.

## Error Handling

Errors should be handled explicitly rather than silently ignored.

## Logging

The application should use structured logging for important runtime events.

## Modularity

Each module should have a clearly defined responsibility.

## Testing

New functional components should have appropriate automated tests.

## Version Control

Commits should describe the change clearly and use consistent commit messages.
